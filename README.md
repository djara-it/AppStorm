# ⚡ AppStorm
**Your Ultimate Android Apps, Music & Web Tools Hub**

A modern, fast, and interactive platform designed to explore, customize, and enjoy the best mobile tools along with a real-time integrated background music player.

[Live Demo](https://djara-it.github.io/AppStorm/) · [Report an Issue](https://github.com/djara-it/AppStorm/issues)

---

## 🚀 Key Features
- **📱 Exclusive App Catalog:** Handpicked selection of top Android apps (Entertainment, AI Editing, Customization, and Performance Optimization).
- **🎵 Integrated Music Dock:** Dynamic background music player powered by YouTube playlists with seamless auto-advance and loop features.
- **🎬 Interactive Guides with Video:** Step-by-step Android optimization guides equipped with direct video support.
- **❤️ Local Favorites System:** Save your favorite apps directly in your browser (`localStorage`) without requiring registration.
- **⚡ Instant Search & Filters:** Fast, real-time filtering by categories, tags, and app names.
- **📱 Responsive & Dark Design:** Sleek, minimalist UI optimized for all screen sizes (Mobile, Tablet, and Desktop).

---

## 🛠️ Built With
- **HTML5:** Semantic document structure.
- **CSS3:** Custom properties, Flexbox, CSS Grid, and responsive layout.
- **JavaScript (ES6+):** Dynamic DOM manipulation, media control, and app mechanics.
- **ESLint:** Code quality enforcement and linting.
